# Перенос «Капитала»

Исходная версия defi: `926b57c07064e84e1ee3e2d5dd2546a58e44ceb5`, локальная ветка `feat/okx-wallet-import`.
База Tommma: `6ac5728` (`dev/process-inbox`). Ветка реализации: `dev/capital`.

## Реализовано

- Общая сессия и навигация Tommma, lazy loading раздела, браузер и Tauri.
- Покупка, конвертация, перевод; CRUD/архив с аудитом; все статусы, комбинированные фильтры, поиск, сортировка, пагинация 20/50/100.
- Исходный расчёт Decimal RUB moving average, комиссии, позиции по активу и месту хранения.
- 10 добавочных Prisma-моделей с владельцем во всех персональных ключах и ссылках, отдельный API `/capital`.
- OKX Exchange и Wallet: серверные подключения владельца, GET-only запросы, фоновые задания, heartbeat, курсоры, raw records, дедупликация, обязательная ручная проверка.
- Экспорт всей CSV-выборки из согласованного снимка БД; JSON v1/v2, совместимое шифрование .defi, атомарный повторяемый restore, напоминание через 7 дней.
- Раздельные IndexedDB-снимки пользователей и окружений; Worker с предварительной загрузкой и резервным расчётом той же Decimal-функцией; отказ от офлайн-записи, очистка после 401/403 и отмена запросов при выходе.
- Read-only exporter исходной схемы и мигратор с dry-run/rollback, digest перед apply и сверкой данных/метаданных.
- CI дополнен PostgreSQL 16 и тестами «Капитала»; инструкция подключения, API и переключения — [README.md](./README.md).

## Исправленные дефекты исходного переноса

- Форма исходного defi преобразовывала `needs_review` при редактировании в completed. Здесь статус сохраняется; явное подтверждение отдельно проверяется формой и API, в том числе после промежуточного статуса импортированной операции.
- Разделение ключа позиции по двоеточию теряло части namespaced ID. Используется JSON-кортеж; добавлен регрессионный тест, прочие исходные расчёты сохранены.
- PostgreSQL-экспорт с 18 нулями после запятой ошибочно воспринимался как превышение точности актива. Restore убирает только незначащие конечные нули, не преобразует значения в number; добавлена проверка старого JSON.
- В подтверждении архивирования автоматическое закрытие AlertDialogAction сбрасывало выбранную запись до отправки запроса. Действие теперь закрывает диалог после подтверждения сервера; неуспех сохраняет возможность повтора.
- Общий транспорт Tommma выставляет application/json даже без тела. Для archive/sync/backup-created добавлено пустое JSON-тело, иначе Fastify отклонял запрос; исправление проверено через UI и тест API-адаптера.
- При первой потере сети модуль Worker мог ещё не быть загружен. Добавлены загрузка при онлайн-чтении и тот же расчёт при недоступности Worker; подтверждено браузером и двумя тестами.

## Границы выпуска

Рабочие финансовые данные и реальные OKX-ключи не использовались. Все изменения записей сделаны только в тестовых БД. Проверка рабочих подключений, production-миграция/перенос, переключение домена и отключение defi — отдельный согласованный этап. Tauri проверен локальной debug-сборкой без изменения updater-конфигурации и без публикации desktop-релиза.

Существующее постороннее изменение корневого `package.json` в коммит задачи не включается.
